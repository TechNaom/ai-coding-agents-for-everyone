Project Preview: Extend a Minimal Coding Agent

This chapter doesn't ship the full Level 2 project yet. Module 3's Level 2 (Assisted) project needs Chapter 8's real depth on file/shell/ git tools first, so it unlocks once that chapter is done — same pattern Chapters 1 and 2 used for the Level 1 project.

What's different this time: you don't have to wait to get hands-on. This chapter's project directory already has a real, working, three-tool reference agent — starter.py — the exact agent built across the lesson. Read it, run it against Ollama, and get comfortable with every line now. When the Level 2 project unlocks after Chapter 8, you'll extend that same agent with a tool of your own from a partial scaffold.

What's here right now

starter.py is the reference minimal agent — download it, install openai, pull a model with Ollama, and run it for real. solution.py is that same agent with a fourth tool added the way an AI coding assistant might hand it back — deliberately not a clean diff. Pair with an agent to produce something like it yourself, then critique what comes back, on the AI-paired page.

What the L2 project will ask you to do Per the course's curriculum map, Level 2 (Assisted) gives you a partial scaffold of this same reference agent and has you add one new tool of your own — a real extension, not a guided rewrite — after Chapter 8 has covered file/shell/git tool design in the depth this chapter deliberately didn't (Chapter 7 kept the toolset minimal on purpose, so Chapter 8 has real room to go deeper).

Why waiting for the graded version matters

Shipping the graded Level 2 project before Chapter 8 would mean asking you to design a new tool's safety boundaries (like the list_files boundary escape you can find in solution.py right now) before you've actually covered what those boundaries need to guard against. The reference agent above is real and runnable today; the graded extension waits one chapter so it tests something you've actually been taught.
