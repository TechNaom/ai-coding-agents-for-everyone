Module 2 Is Complete — Here's What's Next

This chapter doesn't ship its own lab. Module 2's real, gradable lab — "trace a real agent transcript and annotate each loop step" — already shipped on Chapter 4's project page, and Chapter 5 pointed back to it rather than duplicating it. This page does the same, and adds one thing: now that you have all three chapters — the mechanism (4), the failure modes (5), and the context-window constraint underneath both (6) — it's worth a third pass over your own annotated trace, this time watching specifically for where context crowding or dilution might have made a failure mode more likely.

Where this fits Module 2 — How Coding Agents Actually Work: Chapter 4 opened the mechanism and shipped the module's lab, Chapter 5 diagnosed what it looks like when that mechanism breaks down, and this chapter (6) covered the resource constraint — a limited, competitively contested context window, and a codebase that never fits inside it — that makes both harder. That's the full module.

Module 2 assessment

Per the course's curriculum map, Module 2's assessment is a concept quiz plus a failure-diagnosis exercise — distinct from the per-chapter quizzes and exercises you've already done, and covering all three chapters together (the loop mechanism, the four named failure modes, and this chapter's context-window material). That combined assessment lives under assessments/ and is tracked as its own build task, separate from this chapter — it isn't included here so this page doesn't duplicate or pre-empt it.

Coming next: Module 3's first hands-on build

Module 2 has been entirely conceptual by design — no SDK, no code execution, just the mechanism itself. That changes starting with Chapter 7, Build: A Minimal Coding Agent, the reference chapter for this whole course: you'll use the Claude Agent SDK to build a real, working agent loop from scratch, verified against the SDK's actual API surface rather than assumed from memory. It's pinned to the cheapest available model with a low turn cap, so a real run costs fractions of a cent — stated plainly in that chapter's lesson, not buried. Chapters 8 and 9 then extend that same agent with real file/shell/git tools and MCP-based tools, building toward Module 3's own hands-on labs.

Why this page stays short

A third, weaker version of Chapter 4's lab here would dilute the one real transcript-tracing skill this module is teaching — which would be a strange way to end a chapter about avoiding diluted signal. This page's job is just closing out the module honestly: pointing you back to the real lab, naming the real assessment that's still coming, and telling you plainly what Module 3 starts with.
