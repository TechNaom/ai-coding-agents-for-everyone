## Required Checks

AI Coding Agents for Everyone is a focused-topic course (13 chapters vs. RAG's 28), so
the volume bar below is deliberately lower than `rag-for-everyone`'s
template — see `docs/course-architecture.md`, Production Depth Standard.
Depth per item still matters more than count.

- [ ] Lesson starts with a problem, not jargon.
- [ ] Lesson includes core concepts, internal mechanics, architecture/diagram, worked example(s), hands-on lab, failure lab, production scenario, trade-offs, security, performance/cost/scale, common mistakes, thought-process journal, and summary/cheat-sheet.
- [ ] Exercises include at least 6 tasks, with at least 3 production-gear tasks.
- [ ] Practice bank includes at least 6 realistic scenarios.
- [ ] Interview bank includes at least 8 questions spanning beginner/intermediate/senior/architect, each with strong answer, red flag, follow-up, and what this proves.
- [ ] Project includes a meaningful implementation or design artifact, verified runnable end-to-end (not just "looks right").
- [ ] Chapter includes diagrams or visual/text architecture aids.
- [ ] Chapter includes a thinking journal (builder thought process, not hidden chain-of-thought).
- [ ] Navigation follows lesson -> quiz -> exercises -> practice -> interview -> project.
- [ ] Content is original and not copied from reference repos.
- [ ] Any code example has been executed against the real SDK/spec version, not written from memory.
