Chapter 5 Project ~2 min read

This Chapter's Lab Lives in Chapter 4

Module 2's lab — "trace a real agent transcript and annotate each loop step" — is the Level 2 project per the course's curriculum map, and it already shipped with real, gradable content on Chapter 4's project page. It doesn't get repeated here. If you haven't done it yet, that's the right place to go next — and it's worth revisiting even if you have: now that you know the four failure-mode shapes this chapter named, re-reading your own annotated trace with an eye for looping, stalling, compounding mistakes, or a premature "done" will likely surface something you didn't flag the first time through.

Where this fits Module 2 — How Coding Agents Actually Work: Chapter 4 opened the mechanism and shipped the module's lab, this chapter (5) diagnosed what it looks like when that mechanism breaks down, and Chapter 6 covers what happens to it as the conversation grows toward a context limit. One lab, used across the whole module, is more useful than three shallow variations on the same exercise.

Coming next: Module 3's first hands-on build

Module 2 has been entirely conceptual by design — no SDK, no code execution, just the mechanism itself. That changes starting with Chapter 7, Build: A Minimal Coding Agent, the reference chapter for this whole course: you'll use the Claude Agent SDK to build a real, working agent loop from scratch, verified against the SDK's actual API surface rather than assumed from memory. It's pinned to the cheapest available model with a low turn cap, so a real run costs fractions of a cent — stated plainly in that chapter's lesson, not buried. Chapters 8 and 9 then extend that same agent with real file/shell/git tools and MCP-based tools, building toward Module 3's own hands-on labs.

Why this page stays short

A second, weaker version of Chapter 4's lab here would either duplicate work you've already done or dilute the one real transcript-tracing skill this module is teaching. This page's job is just pointing you to where the lab already is, and telling you honestly what's coming next.
