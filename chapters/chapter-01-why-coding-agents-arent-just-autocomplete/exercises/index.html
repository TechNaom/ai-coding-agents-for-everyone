Chapter 1 Exercises ~25 min

Exercises: Why Coding Agents Aren't Just Autocomplete

This chapter is conceptual — no SDK or code execution yet, that starts in Module 3. These exercises build the judgment to tell an agent's loop-driven behavior apart from a single-shot suggestion, and to reason about when each is the right tool.

Exercise standard Six tasks below. At least three are production-gear: harder, ambiguous, real-world judgment calls rather than clean textbook cases.

1 Tag the transcript

You're shown two short transcripts of a developer asking for help fixing a broken date-parsing function. Transcript A: the assistant reads the cursor's surrounding lines and suggests a one-line fix inline. Transcript B: the assistant searches the repo for other callers of the function, reads two of them, edits the function and one caller, then runs the test suite and reports the result. For each, name which one used single-shot autocomplete-style prediction and which one ran an agent loop — and point to the specific action in the transcript that proves it (not just "it felt more thorough").

2 Where would the loop have to stop?

Take the CSV export example from the lesson. If the tool being used were autocomplete-style only (no agent loop), list every step in the sequence — search, read, edit, run tests, read failure, edit again — that a human would have had to trigger manually instead. Count them.

3 Name the observation that changed the plan

In the lesson's example, the agent's original plan didn't include editing _validate_headers. Identify the exact observation (what the agent read or ran) that caused the plan to change, and explain in one sentence why an autocomplete-style tool would never have produced that observation in the first place.

4 (Production-gear) The ambiguous transcript

You're given a transcript where an assistant reads one file, then proposes a multi-line change, then stops — no test run, no second file touched. Is this autocomplete or a very short agent loop that just happened not to need more steps? Explain what additional information (not present in the transcript itself) would let you tell the difference for certain, and what your best guess is without that information.

5 (Production-gear) The overconfident review

A teammate says "I only asked it to fix one function, so I only need to review that one function's diff." You know the assistant they used runs an agent loop, not single-shot suggestions. Write two to three sentences explaining, using this chapter's concepts, why that review plan is risky — and what they should check instead before trusting it's safe to merge.

6 (Production-gear) Pick the right tool for the ticket

You have three tickets: (a) rename a single local variable for clarity, (b) migrate a deprecated logging call to a new API across an unknown number of files, (c) add one new optional parameter to a function you already have open, with a clear default. For each, decide whether reaching for an autonomous coding agent or sticking with inline-suggestion autocomplete is the better fit, and justify each choice using the loop-versus-prediction distinction from this chapter — not just "agents are more powerful so always use them."
