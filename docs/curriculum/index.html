Roadmap

The course mirrors the mcp-for-everyone architecture: chapters grouped into modules, each ending with exercises, a practice bank, interview prep, a project, and a builder thought-process journal. The build-your-own-agent chapters (7 onward) run against a local, open-source model via Ollama by default — zero API cost, zero API key, with a documented option to swap in a hosted provider instead.

Start with Chapter 1 (live now)

Module 1: Using Coding Agents Well

Prompting, scoping, and reviewing an agent's diff like a senior engineer — before any internals.

Outcome: ship a real small feature with a written review log.

Module 2: How Coding Agents Actually Work

The plan/act/observe/repeat loop, named failure modes, and context-window limits — opening the hood.

Outcome: diagnose why an agent looped, stalled, or went off the rails.

Module 3: Building a Coding Agent

A real, working agent from scratch against a local model, real tools, and MCP-based tools instead of hand-rolled ones.

Outcome: a working minimal agent with real tools, tested.

Module 4: Reviewing AI-Generated Code Critically

Detecting hallucinated APIs and logical bugs — the human half of "AI proposes, human reviews."

Outcome: build the habit of validating before trusting.

Module 5: Production & Safety

Sandboxing, permissions, destructive commands, and putting an agent safely into CI.

Outcome: scope an agent's permissions and integrate it into CI safely.

Module 6: Capstone

Design (and partially implement) an agentic workflow for a realistic engineering org.

Outcome: think and design like an architect, not just a builder.

Every Chapter Includes

Lesson, quiz, exercises, practice bank, interview prep, project, and a builder thought-process journal — every hands-on code example tested against a real, running model before it ships.

Outcome: learn like a responsible AI-era builder.
